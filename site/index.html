03 / Good to know

A few practical
details.

Local tools, explicit permissions, and documentation for the parts that matter.

Is Harbor another VM runtime?

No. Harbor assembles the two standalone repositories. Slipway uses Tart and SSH; Porthole observes their activity.

Will updates overwrite my work?

No. Harbor skips dirty worktrees, feature branches and detached HEADs. Updates use fast-forward-only pulls.

Which Macs can use this?

Local Tart VMs need Apple silicon. Porthole runs on macOS 15+ and can watch an existing remote Mac from Intel too.
